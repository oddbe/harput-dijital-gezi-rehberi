# Harput Dijital Gezi Rehberi

Harput'un tarihi ve kültürel mirasını tanıtmak amacıyla geliştirilmiş dijital gezi rehberi projesidir.

## Proje Hakkında

Bu proje ziyaretçilerin Harput'taki önemli tarihi mekanları keşfetmesini kolaylaştırmak için hazırlanmıştır.

Rehber içerisinde:

- Tarihi mekan bilgileri
- Detaylı açıklamalar
- Fotoğraf çekim önerileri
- Google Maps yol tarifleri
- Karanlık mod desteği
- Mobil uyumlu tasarım

bulunmaktadır.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Font Awesome
- GitHub Pages

## Projede Yer Alan Mekanlar

- Harput Kalesi
- Meryem Ana Kilisesi
- Harput Ulu Camii
- Sarahatun Camii
- Harput Basın Müzesi
- Şefik Gül Kültür Evi
- Arap Baba Türbesi
